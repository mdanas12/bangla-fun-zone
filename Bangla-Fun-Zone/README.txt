# Bangla Fun Zone

ফ্রি বাংলা কুইজ ও মিম মেকার ওয়েবসাইটের প্রথম সংস্করণ।

## চালানোর নিয়ম
1. `index.html` ফাইলটি ডাউনলোড/Extract করো।
2. ফাইলটির ওপর ডাবল-ক্লিক করো।
3. Chrome বা অন্য আধুনিক ব্রাউজারে খুলবে।
4. কুইজ খেলো, মিম টেমপ্লেট বেছে নাও অথবা নিজের ছবি আপলোড করে মিম ডাউনলোড করো।

## ফিচার
- মোবাইল ও কম্পিউটারে responsive ডিজাইন
- ৫টি বাংলা মজার কুইজ
- কুইজের স্কোর ও শেয়ারযোগ্য ফলাফল
- ৫টি রেডিমেড মিম টেমপ্লেট
- নিজের ছবি আপলোড করে লেখা বসানো
- PNG হিসেবে মিম ডাউনলোড
- কোনো লাইব্রেরি, API key বা paid service দরকার নেই

## গুরুত্বপূর্ণ সীমাবদ্ধতা
এটি ব্রাউজারে চলা প্রথম সংস্করণ। এতে user account, server/database, admin panel, online leaderboard বা আয়/পেমেন্ট ব্যবস্থা নেই। ছবি শুধু নিজের ব্রাউজারেই প্রসেস হয়। ওয়েবসাইট অনলাইনে প্রকাশ করতে পরে একটি free static hosting service ব্যবহার করা যাবে।
